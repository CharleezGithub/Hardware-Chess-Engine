# chisel-empty

An almost empty chisel project (and adder) as a starting point for hardware design.

To generate Verilog code for the adder execute:
```bash
make
```

Run the tests with:
```bash
make test
```

Cleanup the repository with:
```bash
make clean
```

# Find USB port for FPGA
```bash
ls -l /dev/serial/by-id/
```
